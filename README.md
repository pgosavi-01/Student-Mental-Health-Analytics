# Student Mental Health & Depression Analytics

A Power BI dashboard created as a practical project during my 30-Day Masterclass in Data Analytics.

## 📊 Dashboard Overview

This dashboard provides an interactive view of student mental health, academic performance, and lifestyle-related factors.

## Key Insights
- Total Students
- Depression Cases
- Average CGPA
- High Financial Stress
- Depression by City
- Depression by Age Group
- Depression Rate by Gender
- Financial Stress vs Lifestyle
- Depression Rate by CGPA Range

## 🛠️ Tools & Technologies

- Power BI
- Data Analytics
- Data Visualization
- Interactive Dashboard Design

## 🎯 Project Objective

The objective of this project is to apply data analytics and visualization concepts to explore patterns related to student mental health, academic performance, and lifestyle factors.

## 📌 Features

- Interactive KPI Cards
- Slicers for filtering data
- Multiple visualizations
- CGPA range analysis
- Gender and age-group analysis
- City-wise analysis
- Financial stress analysis
